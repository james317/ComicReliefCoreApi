How do I get a cookie?

Log into dcbservice.com in a normal browser, open DevTools' Network tab, reload the page, click the first request, and copy the full value of the Cookie: request header. See docs/BACKLOG.md in the repo for the exact steps (including how to do this from an iPad/iPhone with no computer handy).
